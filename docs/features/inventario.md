# Gestión de Inventario

## ¿Qué es?
El módulo de inventario es el corazón de tu tienda. Te permite gestionar stock, rastrear productos por **sucursal** y mantener control total de lo que vendes.

## Para qué sirve
- Registrar y actualizar cantidad de productos disponeibles
- Asignar stock a múltiples sucursales simultáneamente
- Prevenir sobreventa (vender más de lo que tienes)
- Rastrear movimientos de stock entre ubicaciones
- Alertar cuando el stock cae por debajo de un límite
- Automatizar cálculos de ganancia/pérdida por venta
- Cargar muchos productos a la vez desde un archivo Excel/CSV o desde una hoja de cálculo dentro del sistema
- Encontrar productos rápidamente con búsqueda, filtros y paginación

## Casos de uso
1. **Tienda multisucursal**: Distribuir stock entre diferentes ubicaciones físicas
2. **Control de existencias bajas**: Recibir alertas cuando un producto está próximo a agotarse
3. **Auditoría de inventario**: Revisar qué se vendió, cuándo y dónde
4. **Ajustes manuales**: Registrar pérdidas, roturas o cambios de stock
5. **Transferencias entre sucursales**: Mover productos de una ubicación a otra
6. **Carga inicial del catálogo**: Subir todos tus productos de una sola vez usando la plantilla de Excel/CSV
7. **Migración desde otro sistema**: Importar un archivo con columnas distintas y mapearlas a los campos de DM Hub

## Características clave
- **Stock por sucursal**: Cada rama tiene su propio inventario independiente
- **Actualización en tiempo real**: El stock se reduce automáticamente cuando se confirma un pago
- **Historial de movimientos**: Registro completo de todas las transacciones de stock
- **Alertas inteligentes**: Notificaciones cuando stock es crítico
- **Exportación de reportes**: Descargar inventario en CSV/Excel

## Carga masiva de productos
Al hacer clic en **"+ Nuevo Producto"** se abre una ventana con dos opciones:

- **Subir archivo Excel/CSV**:
  1. Descarga la **Plantilla CSV** o la **Plantilla Excel**.
  2. Llénala con tus productos y súbela (.csv / .xlsx).
  3. Si tu archivo tiene otros nombres de columna, usa **"Mapear Columnas Manualmente"** para indicar a qué campo corresponde cada una. El sistema adapta el archivo automáticamente a la estructura requerida.
  4. Revisa la vista previa e importa los productos.
- **Editor interactivo (tipo Excel)**: escribe directamente en las celdas o copia y pega bloques de datos desde Excel. Puedes exportar la hoja a CSV o Excel.

## Búsqueda, filtros y paginación
- **Buscador**: filtra productos por nombre o SKU
- **Filtro por estado**, con botón **"Limpiar filtros"**
- **Paginación**: elige cuántas filas ver por página y avanza con "Anterior" / "Siguiente"

## Integración con otras funciones
- Se sincroniza con **Configuración de Pagos** para reducir stock automáticamente
- Alimenta los **Reportes** con datos de rotación de productos
- Conecta con **Sucursales** para distribuir stock
- Se vincula a **Métodos de Pago** para calcular rentabilidad real
- El **Agente de IA del Constructor Visual** puede generar productos y guardarlos directamente en tu catálogo

## ¿Cómo acceder?
Ve a **Productos** en la barra lateral y selecciona **Gestión de Inventario**.
